# Этап 6 — подключение NLP-модели из бакалаврской работы

## Что сделано

- Добавлен `CountVectorizer1.pickle`, сохранён существующий `MachineNB1.pickle`.
- Два артефакта проверяются по SHA-256 перед десериализацией. Загрузка pickle включена только для этих двух разработческих файлов внутри ML-контейнера.
- Python-адаптер преобразует текст через `CountVectorizer.transform`, затем вызывает `GridSearchCV(MultinomialNB).predict`.
- `POST /api/ml/text/predict` принимает **только fileId сохранённого TXT-файла**, а не произвольный путь. BFF проверяет владельца файла.
- История текстовых анализов хранится в новой таблице `TextAnalysisResults`, с привязкой к пользователю, профилю ребёнка и файлу.
- В списке TXT-файлов появилась кнопка «Анализ текста», открывающая окно с результатом и историей.
- Сохранены теги, профили, файлы, видеомодель и формат видеоанализа.

## Проверка

1. Сделайте резервную копию старого проекта и SQLite (если она важна).
2. Остановите старый Compose через `docker compose down` (НЕ `down -v`).
3. Распакуйте этот архив, запустите `docker compose up -d --build`.
4. Откройте приложение. Создайте **тестовый** TXT-файл «Написать текст» для выбранного ребёнка, добавьте теги, сохраните.
5. Нажмите «Анализ текста» в строке файла. После обработки должен появиться класс 0 или 1; он также сохранится в истории.
6. Проверьте `docker compose logs --tail=100 ml-service` при ошибке.

## Важные ограничения

- **Соответствие `CountVectorizer1.pickle` и `MachineNB1.pickle` подтверждено только по числу признаков (3246)**. Неизвестно, использовался ли именно этот словарь при обучении классификатора.
- Не восстановлена исходная очистка/лемматизация рассказов. Это может существенно влиять на прогноз. Нужны оригинальный скрипт предобработки и контрольные истории с ожидаемыми результатами.
- Метки 0/1 не интерпретируются как диагноз или вероятность РАС.
- Версия scikit-learn в Docker — 1.3.0, артефакты получены с 1.2.2. Возможны предупреждения совместимости; после испытаний стоит закрепить совместимую среду.
- Pickle-файлы небезопасно загружать из недоверенных источников. Не разрешайте пользователям загружать артефакты моделей.
- Не размещайте проект публично: текущий Compose по-прежнему содержит тестовые секреты и другие ограничения безопасности.
- В этом окружении не проводилась полная Docker-сборка; проверьте локально.
