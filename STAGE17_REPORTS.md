# Этап 17 — универсальные отчёты моделей

## Что изменилось для пользователя

По кнопке «Результат» открывается единый отчёт. Его состав задаёт адаптер: текст, таблицы, готовые изображения, аудио, видео и скачиваемые файлы. Блоки выводятся в объявленном порядке; изображения загружаются в отчёт, записи открываются в проигрывателе. Большие таблицы показываются порциями, без потери строк. Полный JSON остаётся в свёрнутых технических данных.

Текстовая модель сохранила прежние формулировки «Рассказ отнесён к категории “РАС”», «... “без РАС”» и «Смешанный результат». Алгоритм классификации, предобработка, пороги и веса не менялись. Отчёт содержит итог, показатели и таблицу фрагментов с категориями; доля фрагментов не объявляется вероятностью РАС.

Аудиоадаптер показывает итог, показатели, таблицу интервалов, график активности и проанализированную звуковую дорожку. Это алгоритм выделения громких участков, без классификации РАС.

Видеоадаптер показывает итог, показатели, таблицу движений, график частоты событий при наличии данных, обработанное видео и выгрузки характеристик/временных рядов. Численные характеристики и классификатор не заменены новым алгоритмом. Если обработанное видео не получено, отчёт считается частичным, а доступные данные сохраняются.

## Как подключается новая модель

Используется прежний Python-адаптер, без дополнительных контейнеров и маршрутов React. К `MODEL` добавляется `report_schema` — перечень блоков с id, type, title, required и порядком. Адаптер возвращает `report_blocks` через `make_result()`. Графики строит и сохраняет код адаптера; веб-интерфейс не выбирает оси и не выводит научные заключения из таблиц.

Полная инструкция и пример: `ml-service/templates/README.md`. Шаблон: `ml-service/templates/adapter_template.py`. Рабочие частные реализации: `parent_story.py`, `audio_activity.py`, `movement_video.py`.

Наглядный пример «один текст + одна таблица + три изображения»:

```bash
python scripts/report_demo.py --output-dir report-demo
```

Команде нужно Python-окружение с зависимостями ML-сервиса. Результат — report.json, три PNG и manifest.json в каталоге запуска. Пример находится вне реестра реальных методов, не меняет базу и не оценивает РАС.

## Формат и неполные результаты

- Новый общий формат ответа — `schema_version: 1.3`. Состав отчёта описывается схемой версии 1.0 и сохраняется снимком в самом результате.
- У каждого блока статус ready/unavailable. Отсутствие обязательного блока или его файла даёт partial. Необязательный отсутствующий блок сам по себе не означает ошибку анализа.
- Неверные типы, неизвестные/дублирующиеся id, скрытые столбцы, нечисловые NaN/Infinity и недопустимые ссылки отклоняются как ошибка контракта.
- Старые результаты 1.0–1.2 открываются прежним способом. Они не преобразуются задним числом и не зависят от новой схемы адаптера. Все прежние исходные поля сохраняются.
- Изображения/записи привязаны к владельцу и конкретному запуску через manifest. Веб-ответ не содержит произвольных локальных путей или внешних URL. Существование и границы файлов проверяются в ML-сервисе и BFF. Неактивные форматы скачиваются как файлы, без выполнения HTML/SVG.

## Обновление

Сделайте резервную копию, перенесите исходники полного архива в прежнюю папку проекта, сохранив `.env` и Docker volumes. Выполните:

```bat
docker compose --env-file .env up -d --build
docker compose --env-file .env ps
```

Обновите страницу Ctrl+F5. Для Timeweb добавьте `-f compose.timeweb.yml`. Новые миграции базы не требуются: отчёт сохраняется в существующей истории. Не используйте `down -v`.

Права версии 16.3 сохранены: отчёты и материалы доступны родителю; специалист видит только закреплённые профили, а администратор управляет аккаунтами, существующими профилями и назначениями. Доступы этим этапом не расширялись.

## Что проверено

- 37 тестов Python, включая настоящую текстовую модель и два видеоклассификатора на сохранённых характеристиках, прошли.
- 12 серверных тестов Node с HTTP/SQLite и 34 теста React прошли. Среди проверок: произвольная комбинация текста/таблицы/трёх изображений, сохранение схемы и истории, старые форматы, частичный отчёт, чужие файлы, выход из каталога запуска, проигрыватели, смена выбранного запуска и освобождение blob URL.
- На тестовой копии прежней базы пройден реальный запуск Node → Flask → модели → SQLite для текста и аудио. Текст: 8 фрагментов, 5 категории «РАС»; аудио: 3 участка, готовые PNG и WAV, скачивание файлов и совпадение повторно открытого отчёта с сохранённым.
- Сформирован технический пример с текстом, таблицей и тремя настоящими PNG. Состав проверки — `demo/stage17-verification.json`.
- Production-сборка проверена; остаются предупреждения прежних компонентов. Полная обработка видео через YOLO в этой среде, Docker/Timeweb и визуальный прогон браузера не выполнялись. После обновления проверьте отчёты у себя.
