# Этап 18.2 — карточки детей у родителей

Родителям возвращён прежний вид профилей: карточки детей, карточка «Общие материалы», дата рождения, назначенные специалисты и значок редактирования.

Таблица и поиск по ФИО остаются только у специалиста. Новая кнопка «Обновить» не возвращается. Права доступа и отчёты версии 18 сохранены.

Для обновления сохраните `.env`, рабочие данные и Docker volumes, замените исходники и выполните:

```bat
docker compose --env-file .env up -d --build
```

Обновите страницу через Ctrl+F5. Миграция базы и повторный анализ не нужны.
