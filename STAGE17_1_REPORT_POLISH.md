## Обновление

Сохраните `.env`, рабочие данные и Docker volumes. Замените исходники и выполните из корня проекта:

```bat
docker compose --env-file .env up -d --build
```

Обновите страницу через Ctrl+F5. Для новой формулировки итога видео повторите анализ: уже сохранённые заключения не переписываются. Изменения ширины, таблиц и расположения технических файлов применяются к ранее сохранённым отчётам формата 1.3.

Модели, веса, классификация и права доступа не изменены. Формат результатов остаётся 1.3.
