# Этап 7: навигация, фон и доступность списка ML-моделей

## Исправления

1. Логотип и название «Аутмама облако» ведут на главную страницу `/autmama/`. Кнопка «Материалы» в шапке удалена.
2. В карточке родителя теперь только одна кнопка «← Назад» сверху. Нижняя дублирующая кнопка удалена. «Выход» в шапке завершает сеанс.
3. Убран градиент общего фона и декоративное пятно. Фон теперь ровный светлый `#f8f8f5`. Карточки и кнопки остаются мягкими по цвету.
4. Каталог моделей остаётся видимым даже при задержке или недоступности ML-сервиса; модели получают статус «Недоступна», а не ложное «Готова». Кнопка «Проверить снова» повторяет запрос. Время ожидания ответа Python-сервиса увеличено с 4 до 8 секунд.

## Важное ограничение

Это исправляет **поведение отображения** списка моделей при недоступности Python, но не гарантирует устранения первопричины его недоступности. Если после запуска обе модели «Недоступна», проверьте:

```powershell
docker compose ps
docker compose logs --tail=100 ml-service
docker compose logs --tail=100 bff
```

## Обновление проекта

1. Сделайте резервную копию текущей папки и данных. Обратите внимание, что изменение названия каталога Compose может создать новые volumes и скрыть старые файлы — не удаляйте их.
2. Из старого каталога выполните `docker compose down` (без `-v`).
3. Распакуйте обновлённую версию и выполните `docker compose up -d --build`.
4. Откройте `http://127.0.0.1:3000/autmama/`; при старом кеше браузера нажмите Ctrl+F5.
5. Проверьте навигацию, список моделей и анализ тестового TXT.

Данные пользователей, записи моделей и вывод результатов ML этим этапом не менялись.
