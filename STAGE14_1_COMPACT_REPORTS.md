# Этап 14.1 — короткие пользовательские отчёты

Исправлено смешение пользовательских пояснений и заметок разработчика.

- Текст: короткий заголовок категории и одно пояснение. Словарь, CountVectorizer, pickle, диплом и история разработки убраны из новых выводов и ограничений. Технические значения остаются в подробностях и JSON.
- Видео: «Характеристики движений рассчитаны», «Итоговая оценка по видео пока недоступна». Три основных показателя: длительность, доля кадров с обнаруженной позой, число резких движений. Остальные значения сохранены в подробностях.
- Показатели размещены компактно; пояснения доступны по наведению, без повторяющихся абзацев.
- Одно предупреждение «Результат анализа не является диагнозом». Архивные ограничения и предупреждения находятся внутри свёрнутых технических данных; JSON истории не изменяется.
- Убраны повтор заголовка, подсказка о сохранении запусков, счётчик истории и одиночные селекторы. Выбор модели и истории появляется при нескольких вариантах.
- Готовность сервисов обозначается «Доступен» / «Недоступен», без внутренних комментариев о тестировании.
- Шаблон и инструкция разработчика уточнены: история проекта и происхождение моделей относятся к документации, а не текстам для родителей.

Старая история не переписывается: ранее сохранённые формулировки вывода и значения остаются исходными. Сокращение блоков интерфейса действует сразу; новые короткие выводы адаптеров появляются после повторного анализа.

Проверено: 19 Python-тестов, 10 React-тестов, сборка React (с прежними предупреждениями). Реальный инференс Docker и визуальная проверка браузером не выполнялись. Математика моделей не менялась. Видеоклассификатор не восстановлен.

Обновление: сохранить свои .env и пользовательские данные, перенести исходники, затем из корня проекта:

```powershell
docker compose up -d --build frontend ml-service
```

Обновить страницу Ctrl+F5. База данных и dataset не требуют очистки. Архив содержит все изменения предыдущих этапов.
