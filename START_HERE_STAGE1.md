# ASD Research Platform — этап 1 (на базе MERN_ASD_SHARE)

Это **первый ограниченный патч**, а не готовая версия для Timeweb Cloud.

## Изменено

- Исправлена асинхронная проверка пароля (`await bcrypt.compare`).
- Удаление файла и чтение ссылок ограничены владельцем по JWT.
- Chunk upload проверяет владельца uploadId; создание папки проверяет владельца родительской папки.
- Не отмечаем видео как проанализированное при ошибке ML.
- Не подменяем результат ML выдуманным прогнозом при недоступности сервиса.
- Выключен Flask debug; backend production-режим берётся из `NODE_ENV`.
- Удалён вывод пароля администратора в журнал.
- Frontend использует `/api` через тот же Nginx, а не localhost клиента.
- Появился начальный реестр ML-возможностей (только метаданные) с `GET /api/ml/capabilities` (JWT обязателен).

## Как запустить на Windows (из каталога проекта)

```powershell
docker compose up -d --build
docker compose ps -a
```

Проверьте `http://127.0.0.1:3000/autmama/`, вход и загрузку тестового файла.
Для проверки нового API после входа используйте действующий Bearer access token
для запроса `GET http://127.0.0.1:3000/api/ml/capabilities`.

**Осторожно:** `docker-compose.yml` исходного проекта содержит опубликованные секреты,
административные учётные данные и наружу открытые порты. НЕ размещайте
этот Compose на публичном сервере, особенно с материалами детей.
Имеется незащищённый маршрут видеостриминга, а обработка пользовательских
путей/файлов требует дополнительной проверки. Патч НЕ закрывает все уязвимости.
