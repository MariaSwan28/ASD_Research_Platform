# Этап 11 — понятная регистрация и навигация

## Изменения

- На неавторизованной странице в шапке остаётся только логотип: кнопка «Войти» не дублирует форму входа.
- Форма входа содержит ссылку «Зарегистрироваться»; форма регистрации содержит ссылку «Войти».
- После успешной регистрации сервер возвращает пользовательский объект той же структуры, что при обычном входе. Frontend сохраняет access token и открывает личный кабинет без лишнего повторного входа.
- Убрана неверная подсказка «подтвердите почту»: в текущем прототипе почтовая активация отключена.
- Новые пароли при регистрации должны содержать от 8 до 32 символов, проверка есть на клиенте и сервере. Ранее зарегистрированные пользователи продолжают входить со старыми паролями.
- Кнопка запуска видеоанализа теперь подписана «Анализ», как и для остальных файлов. «Результат» и «Повторить анализ» остались самостоятельными действиями.
- Теги, детские профили, ML-адаптеры, модели и сохранённые результаты не изменены.

## Как обновить без потери данных

1. Создайте резервную копию текущей папки проекта, сохраните отдельно данные из используемых Docker volumes.
2. Распакуйте архив **поверх существующей папки проекта** с тем же compose project name или перенесите только изменённые файлы, сохранив структуру папок.
3. Выполните в папке проекта: `docker compose up -d --build frontend bff`. ML-сервис не менялся.
4. Обновите браузер (`Ctrl+F5`).
5. Проверьте: выход → форма входа → «Зарегистрироваться» → регистрация тестового пользователя → автоматический вход → выход → обычный вход → подпись «Анализ» у видео.

Не запускайте `docker compose down -v`: это удалит Docker volumes. Запуск из новой папки может создать отдельные volumes, из-за чего старые профили и файлы временно не будут отображаться.

## Ограничения

Синтаксис проверен, но Docker build и браузерные сценарии в среде подготовки архива не запускались. Почтовая верификация, лимиты попыток входа, ревизия JWT и полный аудит доступа ещё нужны перед публикацией для реальных родителей. Используйте вымышленные тестовые данные.
