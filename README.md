# ASD Research Platform — Аутмама облако

Демонстрационная платформа хранения материалов о развитии детей и анализа через независимые адаптеры. Стек: React, Node.js, Flask, SQLite, Docker Compose.

Текущий этап: 15.

- Локальный запуск и обновление: [START_HERE_STAGE15.md](START_HERE_STAGE15.md).
- Развёртывание в Timeweb Cloud: [deploy/TIMEWEB.md](deploy/TIMEWEB.md).
- Что изменено, проверено и что остаётся подтвердить: [STAGE15_RELEASE.md](STAGE15_RELEASE.md).
- Шаблон нового адаптера: [ml-service/templates/README.md](ml-service/templates/README.md).
- Инженерные доказательства для диссертации: [RESEARCH_EVIDENCE.md](RESEARCH_EVIDENCE.md).
- Машиночитаемая сводка проверок: [demo/verification.json](demo/verification.json).

Исторические STAGE-документы относятся к прежним версиям. Для текущей конфигурации используйте инструкции этапа 15. Не удаляйте пользовательские Docker volumes при обновлении. Результаты моделей не являются медицинским диагнозом.
